# assets/images

Los mockups de los proyectos están construidos con HTML y CSS (ver `index.html`), por lo que esta carpeta no es necesaria para que el sitio funcione.

Si quieres reemplazarlos por capturas reales:

1. Exporta las capturas en formato `.webp` (ancho recomendado: 1200px, calidad ~80).
2. Guárdalas aquí, por ejemplo `f1-manager.webp`.
3. Sustituye el bloque `.mockup` del proyecto por:
   `<img src="assets/images/f1-manager.webp" alt="Descripción de la captura" loading="lazy" width="1200" height="750">`
